# QuickIPTV — أندرويد (جوال + تلفزيون)

تطبيق IPTV خفيف لحسابات Xtream Codes، يشتغل على الجوال والتلفزيون وأجهزة TV Box (من أندرويد 5).

## المزايا
- **التلفزيون:** قائمة أيقونات جانبية، تنقّل كامل بالريموت، والعنصر المحدد يكبر وعليه إطار أبيض. الأرقام تقفز لرقم القناة، و CH+/CH- أو فوق/تحت يبدّلون القناة.
- **الجوال:** شريط تنقّل تحت، والمباشر فيه الشاشة فوق والتصنيفات أفقية.
- **البث المباشر:** ضغطة = تشغيل في الشاشة الصغيرة، ضغطة ثانية = ملء الشاشة. البرنامج الحالي وشريط التقدم لكل قناة، ودليل البرامج.
- **زر «مباشر»:** إذا وقّفت البث أو رجعت لورا، يتحول لـ «العودة للمباشر» ويرجعك للحظة الحالية.
- **الأفلام والمسلسلات:** تصنيفات، «أُضيف مؤخراً»، المفضلة، صفحة تفاصيل، مواسم وحلقات، والاستئناف من حيث وقفت.
- **دليل البرامج الخارجي (XMLTV):** يتعرّف على القنوات تلقائياً (يتجاهل - و _ والفراغات والجودة وبادئة الدولة)، وتقدر تربط أي قناة يدوياً بالضغط المطوّل عليها.
- **سرعة وخفة:** ExoPlayer بفك الفيديو بقطع الجهاز، بفر صغير للبداية السريعة، القوائم محفوظة على الجهاز (فتح فوري)، والصور بحجمها المعروض فقط.

## طريقة بناء APK بدون أي برامج (GitHub)
1. سوّ حساب في github.com (مجاني) واضغط **New repository**.
2. ارفع محتوى هذا المجلد كامل (اسحب الملفات للصفحة، أو استخدم GitHub Desktop).
3. افتح تبويب **Actions** ← **Build APK**. يشتغل تلقائياً بعد الرفع (أو اضغط **Run workflow**).
4. بعد 5–8 دقايق افتح آخر تشغيل ← تحت **Artifacts** نزّل **QuickIPTV-apk**.

داخل الملف بتلقى:
- `app-universal-release.apk` — يشتغل على كل الأجهزة (استخدمه لو مو متأكد).
- `app-armeabi-v7a-release.apk` — أصغر، لأغلب أجهزة TV Box والجوالات القديمة.
- `app-arm64-v8a-release.apk` — أصغر، للجوالات والأجهزة الحديثة.

## أو من Android Studio
افتح المجلد في Android Studio ← **Build ← Build APK(s)**.

## التثبيت على التلفزيون
انسخ الـ APK لفلاش أو استخدم تطبيق **Send Files to TV** / **Downloader**، وفعّل «تثبيت من مصادر غير معروفة».
